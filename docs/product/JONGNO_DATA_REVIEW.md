# 종로구 TourAPI 데이터 팀장 검수 결과

- 원본: `jongno_tourism.csv`
- 검수일: 2026-08-25
- 검수 범위: CSV 구조·지역 코드·좌표·이미지·콘텐츠 유형·MVP 후보
- 성격: 원본 데이터만 이용한 1차 도메인 검수

## 1. 결론

종로구 MVP를 시작하기에 데이터는 충분하다. 전체 291건 중 우선 콘텐츠 유형인 관광지(12) 68건과 문화시설(14) 57건을 합쳐 125건이다. 이 가운데 좌표·주소·이미지를 우선 확인하여 15건을 1차 후보로 선정했다.

다만 이 CSV에는 운영시간, 휴무일, 외부인 출입 가능 여부, 실제 입구 좌표, 방문자 수가 없다. 따라서 후보 선정은 완료했지만 GPS 인증과 포인트 지급은 아직 활성화하지 않는다.

## 5. 보류 또는 제외 기준

- 북촌한옥마을, 부암동, 북악산처럼 범위가 넓은 장소는 `AREA`로 분류한다.
- 여행코스나 골목 전체는 단일 좌표 인증 대상에서 제외한다.
- 같은 좌표에 여러 콘텐츠가 있으면 사용자에게 의미 있는 대표 장소 하나를 우선 선택한다.
- 학교·기관 내부 장소는 외부인 출입 가능 여부 확인 전 인증을 차단한다.
- 이미지가 없어도 탐색 목록에는 표시할 수 있지만 기본 이미지를 사용한다.
- 유명 관광지는 데이터에 있더라도 Local Flag의 ‘숨은 명소’ 기준을 통과하기 전에는 추천 후보로 확정하지 않는다.

## 6. 앞서 합의가 필요했던 네 질문에 대한 판단

1. **선택한 카테고리의 데이터가 충분한가?**  
   관광지와 문화시설이 125건이므로 종로구 MVP에는 충분하다.
2. **단일 GPS 좌표 인증에 적합한가?**  
   개별 건물·유적은 후보가 될 수 있지만 넓은 지역과 탐방로는 별도 검수가 필요하다.
3. **UI에서 카테고리를 구분해야 하는가?**  
   1주차에는 구분 없이 표시하고, 이후 관광지·문화시설 필터를 추가하는 것이 적절하다.
4. **축제 시작일과 종료일을 처리할 수 있는가?**  
   현재 CSV에는 시작일·종료일 열이 없어 처리할 수 없다. 유형 15의 상세정보 API에서 날짜를 추가로 받아야 한다.

## 7. 팀장이 다음으로 직접 확인할 일

1. 15개 후보의 공식 상세정보에서 운영·휴무·예약 여부를 확인한다.
2. 지도 위성·거리뷰 또는 현장 조사로 실제 입구 좌표를 확인한다.
3. ‘숨은 명소’ 여부를 판단할 인지도 근거를 추가한다.
4. 조건부 후보는 안전·접근성 문제가 해결된 경우에만 인증을 켠다.
5. 최종 10개를 확정하고 각 장소의 포인트를 결정한다.

## 8. 개발팀 전달사항

- 백엔드는 `data/jongno_mvp_shortlist.json`을 정규화 예시로 사용한다.
- 프론트엔드는 `checkInEnabled=false`를 ‘둘러보기 가능, 인증 준비 중’으로 표시한다.
- UI/UX는 이미지 없음, 마커 겹침, 조건부 후보 상태를 설계한다.
- 축제 데이터는 상세 날짜가 추가될 때까지 지도 기본 목록에서 제외한다.
