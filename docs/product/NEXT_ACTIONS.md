## P3 — 정책과 발표 준비

- 숨은 명소 선정 기준을 수치화한다.
- 카테고리·접근성·인지도에 따른 포인트 기준을 정한다.
- 사용자 3~5명으로 지도 탐색과 방문 인증 흐름을 테스트한다.
- 문제, 해결 방식, 데이터 근거, 통합 데모를 발표 흐름으로 정리한다.

## 팀장의 매일 확인 루틴

1. 오전에 각 담당자의 오늘 산출물과 막힌 점을 확인한다.
2. API 계약 또는 정책 변경은 문서에 먼저 기록한다.
3. 오후에 실제 통합 화면으로 확인하고 구두 완료 보고만으로 종료하지 않는다.
4. 미완료 작업에는 담당자, 다음 행동, 기한을 반드시 남긴다.
