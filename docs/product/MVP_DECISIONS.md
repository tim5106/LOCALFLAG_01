# Local Flag 1주차 MVP 의사결정안

- 작성일: 2026-08-25
- 담당: 기획·도메인 팀장
- 상태: 1주차 연동 회의용 초안

## 1. 이번 회의의 완료 기준

종로구 TourAPI 관광지 10개 이상을 백엔드가 공통 형식으로 제공하고, 프론트엔드가 이를 카카오 지도에 마커로 표시한다. 사용자가 마커를 누르면 관광지 이름·주소·이미지 또는 대체 이미지가 보여야 한다.

로그인, 포인트 적립, 실제 GPS 인증 저장은 이번 회의의 완료 범위에서 제외한다.

## 2. 현재 채택한 범위

| 항목 | 결정 | 비고 |
| --- | --- | --- |
| 시범 지역 | 서울 종로구 | `areaCode=1`, `sigunguCode=23` |
| 우선 콘텐츠 유형 | 관광지(12), 문화시설(14) | 숨은 명소 후보 확보에 우선 사용 |
| 보류 콘텐츠 유형 | 축제·공연·행사(15) 10건, 레포츠(28) 1건 | 축제 날짜 열이 없고 레포츠 수가 부족해 현재 제외 |
| 제외 콘텐츠 유형 | 여행코스(25) | 단일 GPS 좌표 인증과 맞지 않음 |
| 지도 | Kakao Maps JavaScript SDK | 프론트엔드 키·도메인 등록 필요 |
| 이미지 누락 | 서비스 기본 이미지 표시 | 깨진 URL도 같은 방식으로 처리 |
| 등급·보상 | 검토 전 `UNRATED`, 보상 미표시 | 팀장 검토 후에만 노출 |

## 3. GPS 인증 가능성 분류

| 분류 | 의미 | MVP 처리 |
| --- | --- | --- |
| `POINT` | 한 좌표로 방문을 대표할 수 있음 | 접근 지점 확인 후 인증 후보로 사용 |
| `AREA` | 전통마을·관광단지처럼 여러 입구와 넓은 구역을 가짐 | 대표 입구 또는 반경을 별도 조사하기 전 인증 차단 |
| `EXCLUDE` | 이동 코스, 폐쇄 시설 등 단일 좌표 인증이 부적절함 | 목록과 인증 대상에서 제외 |

`POINT`라도 외부인 접근 가능 여부와 실제 입구 좌표를 확인하기 전에는 `checkInEnabled=false`로 둔다. 넓은 전통마을이나 여러 입구가 있는 관광단지를 단일 중심 좌표만으로 인증하면 도로·주거지에서도 인증될 수 있으므로 `AREA`로 분류한다. :codex-annotation{index="1"}

## 4. 위치 인증 정책 초안

- 관광지 좌표와 사용자 좌표의 거리: 100m 이내
- 사용자 GPS 정확도: 50m 이하일 때만 판정
- 위치 측정 시각: 요청 시각 기준 2분 이내
- 같은 사용자의 최초 성공 방문만 포인트 지급
- `AREA` 장소는 대표 입구 또는 지오펜스가 정해질 때까지 인증 비활성화

위 수치는 구현 계약을 맞추기 위한 초안이며, 현장 테스트 후 조정한다.

## 5. API 필수 정보

목록 화면에는 최소한 다음 정보가 필요하다.

- `id`, `title`, `address`
- `location.lat`, `location.lng`
- `contentTypeId`, 카테고리 코드
- `imageUrl`, `thumbnailUrl`
- `geometryType`, `checkInEnabled`, `checkInRadiusM`
- `reviewStatus`, `grade`, `rewardPoints`

원본 TourAPI 필드와 서비스 필드의 상세 대응은 [TOUR_API_MAPPING.md](./TOUR_API_MAPPING.md)를 따른다.

## 6. 이미지 처리 규칙

1. `firstimage`가 정상 로드되면 대표 이미지로 사용한다.
2. 비어 있거나 로드에 실패하면 기본 이미지를 표시한다.
3. `http` 이미지가 브라우저 보안 정책으로 차단되는지 실제 화면에서 확인한다.
4. 이미지 저작권 구분 코드(`cpyrhtDivCd`)는 원본 데이터에 보존한다.
